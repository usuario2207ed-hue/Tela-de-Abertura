# 🔋 Tela de Abertura 

Este projeto mostra uma animação de uma bateria carregando.
Quando a carga chega a 100%, o usuário é levado automaticamente para o site principal.

🔋 Como funciona

A tela exibe uma bateria enchendo aos poucos.

A porcentagem aumenta conforme a animação.

Quando chega ao final, o sistema abre o site configurado.

Funciona em celular, tablet e computador.


---

Pode ser usado direto no navegador ou instalado como um **aplicativo** no celular/PC.
